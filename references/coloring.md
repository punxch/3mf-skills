# 区域分色与材料

## 划分区域

先读取当前耗材表和逐面涂色，检查对象是否已经分件。一个连通网格仍可同时包含皮肤、头发、发箍和衣服；连通组件不能替代语义分区。

对照多视图和用户示意图建立种子区域，必要时结合曲率、凹折边界、图切分和面片 ID 预览。检查遮挡处：从一侧透过头发间隙选到的面，可能属于另一侧皮肤或蝴蝶结。无法可靠区分时展示局部预览确认，不凭“顶部带纹理”推断它就是发箍。

选区数据应记录源文件校验值、包内模型路径、对象 ID、面数及标签含义。源文件或拓扑变化后，重新核对选区，不继续使用旧编号。

## 写入涂色

导入 `mf3_tools.archive.rewrite_triangle_paint`。`selection` 是一维整数/布尔数组；`codes` 是“标签 → 已验证的 Bambu 涂色编码”。未映射标签保留原属性字节。传入 `object_id` 时，数组对应该对象的三角面顺序；不传时对应整份 XML 中三角面的顺序。

下面的例子只适用于已经确认第 4 个耗材槽位存在、且使用该 Bambu 整面编码的项目：

```python
# selection 中 0 表示保留，1 表示整面改用槽位 4。
changed_xml = rewrite_triangle_paint(
    original_xml, selection, {1: "1C"}, object_id="1"
)
write_archive(source_path, output_path, {model_part_path: changed_xml})
```

该函数支持自闭合 triangle 标签及可选命名空间前缀，拒绝计数不符的选区。`paint_color` 是 Bambu 的面涂色扩展，不等同于标准 3MF 的材质属性。不要把这段代码直接当作所有切片软件的通用材质编辑器。

在本项目验证过的整面编码中，耗材槽位 1、2、3、4、5、6 分别为 `4`、`8`、`0C`、`1C`、`2C`、`3C`。它们不是简单的颜色十六进制值。更高槽位或不同编码版本应依据对应切片器实现确认，并通过导入/导出验证。

原有长字符串可能描述细分三角面的多种颜色。未选面必须完整保留；选择整面会替换该面全部细分涂色。如果用户只要求修改面内一小部分，先细分/解码或用切片器绘制，不声称整面替换等价于局部修改。

## 新增材料

仅修改耗材列表中已有颜色，会改变引用该槽位的所有区域；要独立上色，应增加槽位并只让目标面引用新槽位。

逐项核对当前项目配置的含义：

- 耗材颜色、材料类型、预设、直径、温度和其他按耗材存储的字段。
- 每耗材、每喷头或每喷头变体的映射和索引。
- 冲刷矩阵与对应向量、打印板上的材料映射。

不能依据数组长度就批量扩展所有字段；打印机硬件、兼容机型和喷头配置可能恰好具有相同长度。复制兼容的已有材料预设，并核对该版本的字段结构。新增颜色的冲刷量使用切片器的计算或可解释的默认值，不能将未调校数值宣称为打印优化结果。

保留原有材料顺序，避免旧面片引用整体偏移。更新受影响的预览，保留与本次修改无关的项目配置。

## 验证

颜色修改前后，对比局部顶点、三角面索引、组件与 build 变换。工具的 `compare` 是世界坐标检查；若要求底层几何数据也完全不变，还要比较模型 XML 去除涂色属性后的内容以及原组件/摆放条目。

按选区检查新旧涂色；未选面的字符串必须一致。检查槽位是否存在，并以保存后的颜色记录生成正面、背面和局部预览。最后按 [交付验证](validation.md) 检查 Bambu Studio 是否正确识别材料和区域。
